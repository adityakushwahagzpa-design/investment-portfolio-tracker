# Investment Portfolio Tracker | Excel

An Excel tracker for a sample investment portfolio across **stocks, ETFs, alternatives and cash**.

## Build
- Holdings with shares, cost basis, current price, market value and gain/loss ($ and %)
- Portfolio weights and asset-class allocation
- Top holdings ranking and summary totals

## Snapshot (Oct 2026)
- Market value **$113.8K** against a cost of $81.1K: gain of **$32.7K (40.3%)**
- Allocation: stocks 54%, ETFs 32%, alternatives 14% (gold, silver, bitcoin ETF); cash ~9% of the total
- Largest holding: NVIDIA (12.5% weight, +99%)
